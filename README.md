Інтерактивний дашборд аналізу навчальної успішності учнів (Power BI). Три сторінки: загальний огляд KPI за класами/предметами, ефективність по класах та учнях з виявленням негативних оцінок, аналіз динаміки успішності в часі (percentile-аналіз, MoM%). Шкала оцінювання: 0-13 балів. Дані — навчальний датасет GoIT.
Інструменти: Power BI, DAX, Power Query
